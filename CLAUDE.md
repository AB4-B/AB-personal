# Knit Guide: project rules

## Visual style (Amanda's preferences)
- No coloured accent bars. Do not use a thick `border-left`, `border-top` or similar side/top strip on panels, steps, cards, warnings or quotes. She dislikes them.
- Show emphasis with background tint, spacing, weight or an icon plus label instead. Never rely on colour alone.
- Keep text modest: instruction text about 18px, not large display sizes.
- Use the design tokens in `knit-guide/src/theme.css`; do not hard-code colours in components.
- Palette and layout follow the approved reference mockup (green primary, terracotta Quick Stop, gold only for NEEDS REVIEW, red only for errors).

## Working rules
- Never commit or deploy copyrighted patterns (the DROPS fixture stays local and git-ignored).
- Do not merge to main. Deploy only to the existing GitHub Pages `gh-pages` branch.
- Reply to Amanda starting with "Amanda,", short and direct, with [Certain]/[Likely]/[Guessing] tags on factual claims.
